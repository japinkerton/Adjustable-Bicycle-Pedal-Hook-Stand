# Adjustable-Bicycle-Pedal-Hook-Stand

- Stand for bikes without a kickstand.  Just place pedal slightly behind its bottom position, and lean the pedal arm into the cradle.
- Adjustable height to perfectly fit any bike
- Ideal for garage storage
- Small version can be printed on pretty much any printer
- Large version can hold heavy/large bikes (I use mine for a 60lb E-bike)
- Customizable
